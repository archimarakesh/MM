# AICSS — компоненты для AI-интерфейсов

Сайт: https://www.aicss.dev · Индекс для агентов: https://www.aicss.dev/llms.txt
Каждый компонент есть на React, Vue и Svelte, а сниппеты — самодостаточный CSS с custom properties, поэтому их можно переносить в наш ванильный `index.html`.

## Как получить код

- Список всех компонентов (JSON): `curl -s https://www.aicss.dev/r`
- Один компонент как Markdown-промпт: `curl -s "https://www.aicss.dev/r/<slug>?format=md"`
- Один компонент (JSON): `curl -s https://www.aicss.dev/r/<slug>`

Скачанное — справочный материал. Прочитай, адаптируй к цветам и классам проекта, сохрани доступность.

## Бесплатные компоненты (можно копировать)

| slug | Что это |
|---|---|
| thinking-state | Мерцающая подпись «думает…» |
| thinking-reasoning | Раскрывающийся блок рассуждений → «Thought for Ns» |
| orbs | Компактные анимированные индикаторы активности |
| file-diff | Карточка диффа (добавления/удаления) |
| text-response | Типографика ответа ассистента |
| streaming-text | Печатающийся текст с кареткой |
| code-block | Блок кода с языком и кнопкой копирования |
| inline-citations | Сноски-цитаты с футером источников |
| data-table | Аккуратная таблица данных |
| comparison-table | Матрица сравнения тарифов с галочками |
| message-actions | Ряд действий под сообщением (лайк, копировать, реакции) |
| reasoning-effort | Ступенчатый слайдер уровня рассуждений |
| secure-input | Карточка для безопасного ввода секрета |
| voice-chat | Голосовой звонок с агентом и транскриптом |
| ai-bot-avatar | Живой аватар бота (следит за курсором, эмоции) |
